# Third-party files

The release zip contains `SimConnect.dll`, unmodified, from the Microsoft
Flight Simulator 2024 SDK. It is Microsoft's, under the SDK license in
`MSFS SDK EULA.pdf`, and is not covered by SkyDemonConnect's Apache License
2.0. It is included only so that SkyDemonConnect works without installing the
SDK.

`SimConnect.dll` needs the Microsoft Visual C++ 2015-2022 runtime (x64),
which most PCs that run MSFS already have; otherwise install
`vc_redist.x64.exe` from Microsoft.
